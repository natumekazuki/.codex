# v7.2.2

WithMateの[協同ガイド](https://github.com/natumekazuki/.codex/blob/16a5b10183becf4bf606c8513f6f858f6231bb6e/docs/guides/withmate-collaboration.md)を、v7.0.1-preview.2の親子Sessionの扱いに合わせます。

## 変更内容

- 通常子の作成では作成元の実行中Turnから権限を引き継ぎ、異なるProviderで同等の制限を維持できなければ作成しません。通常送信では受付時の宛先の保存権限を使い、どちらも呼出時に権限を上書きしません。Model・Depthの選択や作業の操作許可とは区別します。
- Reply Toは宛先・実送信元・操作許可とは区別し、返信対象が文脈にない場合だけ、必要な保存内容を正確な参照で確認します。
- 協同ガイドやREADMEなどから重複した案内や補足リンクを取り除き、現行の契約と手順に沿って読めるようにします。

## 互換性・利用上の注意

既存のWithMate契約に合わせた文書修正です。実行時は現在提供されるSession MCP契約を優先します。Model・Depthが原因で未受付と確定した場合の再送、受付不明時の照会、設定やSkillの利用手順は変わりません。WithMate本体や端末設定の変更は含みません。
