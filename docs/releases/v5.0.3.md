# v5.0.3

review-test-valueが、固定baseに含まれる動的タイトルのTypeScript testを削除した差分で停止する問題を修正しました。

## 修正内容

- [Git差分抽出](https://github.com/natumekazuki/.codex/blob/5098b05ba83f0c000eb35850a01ea184346e9756/skills/review-test-value/references/git-selection-v1.md)で固定baseの動的test titleを評価せず、一つのsource declarationとして抽出します。file全体または個別宣言の削除では、削除前の宣言全文を`DELETED.before`へ保持します。現行のstatic titleへ一意に対応する場合は`SURVIVED.before`へ保持します。
- [TypeScript adapter](https://github.com/natumekazuki/.codex/blob/5098b05ba83f0c000eb35850a01ea184346e9756/skills/review-test-value/references/source-adapters-v1.md)の`source.symbol`では、動的titleを`[title expression: <式のsource text>]`として表示します。loopやparameterized caseのruntime展開、タイトル式の実行、対象の手動除外は行いません。
- [Codex Issue #124](https://github.com/natumekazuki/.codex/issues/124)の修正を、Codex・Claude・OpenCodeの独立したSkillへ同じ条件で反映しました。

## 互換性

CLI、構造化resultのschema、metadata v2、adapter識別子を維持する互換修正です。現行snapshot・明示pathの動的title、不正metadata、syntax error、その他の未対応構文は引き続き失敗として扱います。正常なv1 metadataやmetadata未付与の削除前testを歴史的証拠として保持する契約も維持します。依存追加、設定変更、migrationはありません。

## 検証

- Python・多言語adapterの決定論的回帰testは、3repositoryで各115件成功しました。
- task baseから変更testの5 records・5 transitionsを抽出し、diagnosticsなしを確認しました。全recordの独立read-only審査と、metadata説明の局所修正後の再確認を完了しています。
- 利用側の同じ固定baseからの差分で、修正前のexit 1を再現し、修正後のexit 0を確認しました。既存108 transitionsを保持し、動的タイトルの削除前宣言1件を追加しています。929～991行の全文を固定baseと照合しました。

## 適用範囲と既知の残件

本版はrepositoryの配布資産の公開です。端末localのruntime配置は含まず、実設定・認証・Memory・共有記録・外部管理Skillと利用側の製品sourceを変更しません。repositoryのpublic設定を維持します。利用側の全record審査・製品commitは別の作業です。

[Claude Issue #1](https://github.com/natumekazuki/.claude/issues/1)のSession Graph並行保存testの検出力改善は既存の別件として継続管理し、本版へ含めません。
