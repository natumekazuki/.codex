# v7.0.3

WithMateでユーザーの回答が必要な質問を見落としにくくする互換修正版です。

## 変更内容

- [協同guide](https://github.com/natumekazuki/.codex/blob/0a82e322512a47dbfcc77ab10c383b4b0962faf5/docs/guides/withmate-collaboration.md)で、回答が必要な質問はCoordinationを優先し、既存の相談は必要に応じてユーザーへ引き継ぐことを明記しました。
- Coordinationが利用できない場合のProvider質問機能と操作承認の区別、結果不明時の重複防止、通常会話で受けた回答と相談の照合・解決を整理しました。

## 互換性・更新時の注意

Coordination・Providerの操作契約、承認権限、Session間の配送範囲は変更しません。既存homeへは対象文書の差分だけを反映し、実設定・認証・履歴を上書きしないでください。

## 確認範囲

3製品の文言・利用経路と差分を静的に照合しました。新しいSessionでの生成応答、実配送、回答後の再開はこの確認に含まれず、実行したものとは扱いません。
