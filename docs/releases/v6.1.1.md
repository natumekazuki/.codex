# v6.1.1

WithMateの委譲依頼を、共通手順の再掲ではなく案件固有の目的・条件・成果に絞る修正です。

## 変更内容

[協同ガイド](https://github.com/natumekazuki/.codex/blob/baacecac4a07904981931e908d9586e90c3f6c32/docs/guides/withmate-collaboration.md)の依頼段落を更新しました。共通の読込・審査・禁止事項・相談や報告の手順は入口参照に集約し、実行設定はAPIの所定引数へ渡します。参照できない背景や誤解しやすい条件は本文へ補足し、担当内の進め方は受け手へ任せます。

## 互換性

指示表現の互換修正です。必要な審査・報告義務、操作権限、データ保護、Skill・CLI・配置入口とSession Graphの契約は変更しません。実設定・認証・Memory・履歴は更新対象外です。

## 確認範囲

3製品のガイド一致と差分検査を実施しました。同じmodel・Character・入力条件を使った独立した変更前後の依頼文生成で、参照可能な場面では共通手順の再掲が減り、参照不能な対照場面では必要な案件条件・検証項目・権限が維持されることを確認しました。

生成比較はGPT-6.1 Solによる2場面各1回の限定確認です。Claude/OpenCode固有modelの応答、実案件のCrew配送・受領後の作業を検証したものではありません。
