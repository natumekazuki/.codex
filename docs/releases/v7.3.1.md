# v7.3.1

[共通の作業規約](https://github.com/natumekazuki/.codex/blob/089be5b05d87fcfa500c384e7d8f28e4450faed5/AGENTS.md)を整理し、依頼された結果と任された範囲を基準に、手段はエージェントが選ぶことを明確にします。根拠が足りない場合は結論を限定し、権限が足りない場合はその操作だけを止めます。

## 変更内容

- [設計の判断](https://github.com/natumekazuki/.codex/blob/089be5b05d87fcfa500c384e7d8f28e4450faed5/docs/guides/design-decisions.md#誰の判断が必要か)では、任された範囲で決められない共有方針だけを確認します。[UIの補助説明](https://github.com/natumekazuki/.codex/blob/089be5b05d87fcfa500c384e7d8f28e4450faed5/docs/guides/ui.md#主内容と補助説明の境界)も、必要で依頼の範囲内に収まる場合は文案ごとの承認を取り直しません。
- [配布時の確認](https://github.com/natumekazuki/.codex/blob/089be5b05d87fcfa500c384e7d8f28e4450faed5/README.md#配布時の確認)では、変更が影響する契約を確かめます。対照例や条件を揃えた生成比較は一律の受入条件にしません。出力の比較自体が依頼された場合は、比較に必要な条件を揃えます。

## 互換性・更新時の注意

破壊的な操作や公開に必要な承認、情報保護、製品・業務契約による承認、既存の必須CIや専門審査は変わりません。手動で配置している場合は、共通入口と関連ガイドを同じ版に揃えてください。設定やSkillの移行は不要です。
