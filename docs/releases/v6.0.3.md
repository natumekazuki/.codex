## 適用範囲と確認限界

本版はrepositoryの配布資産です。実設定・認証・Memory・既存共有記録・外部管理Skillとrepositoryの可視性設定を変更しません。

独立reviewの3ケースは架空入力に対する判断確認であり、競合・通信障害の実注入試験ではありません。新規SessionでのSkill発見、resume/Compactの実動作、Claude/OpenCode providerの実MCP接続、WithMate画面の描画は未確認です。配布版の公開、ローカルへの配置、新規Sessionでの有効な指示・挙動の確認を区別します。
