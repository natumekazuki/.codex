# v7.2.1

親子Session間の通常送信で、Model・Depthが原因で拒否された場合の復旧手順を明確にします（[#160](https://github.com/natumekazuki/.codex/issues/160)）。

## 変更内容

[協同ガイドの通常送信](https://github.com/natumekazuki/.codex/blob/8a623290a65458ecfd42f29949b9af181b229e6f/docs/guides/withmate-collaboration.md#通常送信と実行中の補足)に、Model・Depthが原因で未受付と確定した場合の手順を追加します。送信元が宛先のカタログと選定方針に従い、その送信のModel・Depthだけを選び直し、新しい `requestId` で再送します。適合候補がなければ不足を報告します。受付結果が不明なら再送せず、元の `requestId` と正確な宛先で照会します。完了報告も同じ照会手順を参照します。

## 互換性・更新時の注意

既存の通常送信に対する文書修正です。WithMate製品・API・配布設定は変更しません。保存済みの既定値や権限の変更、製品による自動代替は行いません。

## 確認範囲

v7.2.0からの文書差分と、未受付・候補なし・受付結果不明の扱いを静的に照合しました。文案の検討時には、無効なModelと非対応のDepthで未受付となり、適合するModel・Depthを指定した別IDの送信が受理されることを確認しています。今回の文書変更後の実送信は再試行しておらず、通信断などによる受付結果不明の実機再現は行っていません。
