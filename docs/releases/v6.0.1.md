# v6.0.1

review-test-valueが、宣言外へ投影される空白保持行を含む一対多のtest置換で停止する問題を修正しました。

## 修正内容

- [Git差分抽出](https://github.com/natumekazuki/.codex/blob/a8218fe2dd2d722a5c01fe671eb63299101d4579/skills/review-test-value/references/git-selection-v1.md)の一対多所有判定に限り、空白だけの保持行を判定材料から除外します。全非空白保持行が複数の未対応宣言内へ投影される場合、旧recordを`DELETED.before`へ分離し、新recordは他の旧recordへの一意な対応がなければ`ADDED.after`へ保持します。
- 本文・位置・metadataは空白も含めて保持します。単一宣言への候補絞込み、宣言外の非空白行、内容と位置の競合、不正metadataに対する失敗条件は維持します。
- [Codex Issue #129](https://github.com/natumekazuki/.codex/issues/129)の修正をCodex・Claude・OpenCodeの独立したSkillへ反映しました。直接比較とfirst-parent隣接区間の両方に同じ判定を適用します。

## 互換性

CLI、構造化resultのschema、metadata v2、adapter識別子を維持する互換修正です。一対多置換の空白行だけを除外する条件を明示し、曖昧な対応付けの一般的な救済、部分出力の成功扱い、手動の対象除外は導入しません。依存追加、設定変更、migrationはありません。
