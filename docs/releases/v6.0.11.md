# v6.0.11

WithMate v6.5.0-preview.3に合わせ、背景Memory/Affectの管理と参照範囲を明確にしました。

## 変更内容

- [WithMate利用guide](https://github.com/natumekazuki/.codex/blob/28451284944ddaa33dde39d66260e3824283ed1b/docs/guides/withmate.md)に、背景Memoryの登録・訂正・忘却、用途別の書込target、対象Memoryのappend＋supersedesによる訂正を明記しました。読取可能な範囲をそのまま書込範囲と扱いません。
- 背景Affectのcorrectは有効な用途bindingの管理権限に従うこと、通常turnの訂正・resetの権限と背景reset禁止を維持することを明記しました。自然な感情変化を過去eventの誤りとは扱いません。
- [Session Graph Skill](https://github.com/natumekazuki/.codex/blob/28451284944ddaa33dde39d66260e3824283ed1b/skills/session-graph/SKILL.md)に背景三用途の参照限定を追加しました。元Mainの共有Graphを読むだけで、通常作業の記録手順を背景writeへ適用しません。Glossaryも許可primary checkoutのread-only参照に限定します。
- 背景の共通prompt・SessionFolder共有・実Character/Affect ownerを区別し、設定を迂回した二重注入や、参照材料の過去の指示の実行を避ける境界を整理しました。
- [READMEの仕様参照と確認観点](https://github.com/natumekazuki/.codex/blob/28451284944ddaa33dde39d66260e3824283ed1b/README.md)を[WithMate v6.5.0-preview.3](https://github.com/natumekazuki/WithMate/blob/2b1fda1fb268708e849b8da270c74d752209fe3b/docs/releases/v6.5.0-preview.3.md)へ更新しました。CodexのSkill起動例も通常作業と背景参照を区別し、自動起動policyとMCP依存は維持しました。

## 互換性

既存の指示・Skillの互換修正です。通常会話からの自発的な保存・appraisalや背景失敗の代行を許可せず、自然文全体へのCharacter表現、主体・事実・数値・引用の保持、外部成果物の文体を維持します。

Skill名、MCP呼出契約、hook、model・権限・接続設定、コード・testは変更しません。実設定・認証・既存Memory・Graph・カスタム指示を保護し、データ移行・既存記録の一括変換・独自storeの追加は行いません。

保存済みの背景指示は空文字列も含め自動更新されません。新しい標準管理本文へ切り替える場合はSettingsの該当用途でUse Presetを選びます。配布物の更新とは別操作であり、本リリースではSettingsを変更しません。

## 確認

- 3者のguide・Skill・READMEの該当方針がhost固有の入口名を除いて一致すること、通常作業と背景用途の権限を分離していることを確認しました。
- 既存のSkill validatorは3件とも成功しました。Codexのmetadata YAML解析と呼出名・自動起動policy・MCP依存の維持も確認しました。
- 変更差分の静的review、差分check、release noteの固定commit参照先を確認しました。

## 確認限界

新規host SessionでのSkill発見・実際の行動、背景のcorrect/forget・認可拒否・prompt/ownerの実行時挙動は未検証です。静的な指示整合を外部runtimeの動作保証とは扱いません。

Session Graph Skillのactor/origin等の新runtime契約への同期は、既存の[Codex Issue #135](https://github.com/natumekazuki/.codex/issues/135)で別に管理します。本版のSkill変更は背景用途の参照限定に限ります。
