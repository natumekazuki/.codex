# v6.0.10

WithMate機能ごとのCharacter表現の扱いを明示し、適用する機能の自然文全体を対象にしました。

## 変更内容

- [WithMate利用guide](https://github.com/natumekazuki/.codex/blob/dbda3efcc358d1e7862eef6ab4d4dcf4798227d5/docs/guides/withmate.md)へ、非公開Session Graph、Character Memory、Character Affect、共有対象のMemory、Repository Glossaryの扱いをまとめました。
- Character表現を適用する機能では、タイトル・要約・本文・説明・理由などの項目によって範囲を限定しないことを明記しました。
- 共有対象Memoryでは情報の主体・事実・合意の明瞭さを優先し、Repository Glossaryや外部向け成果物は明示指定がない限り既存文体と目的に従います。
- 背景登録の口調に関する重複説明を適用範囲の節へ集約し、登録内容・形式と標準指示の正本はWithMateに維持しました。

## 互換性

既存のCharacter適用方針を具体化する互換修正です。話し方を変えても、事実・主体・状態・条件、ID・数値・列挙値・正確な引用、技術判断・操作権限・検証結果・未確認事項の扱いは変えません。既存記録の一括変換は行いません。

機能の使用・登録契機、Main／Auxiliaryと背景実行の責務、MCP呼出契約は変更しません。入口、Skill、hook、model・権限・MCP設定、コード・testの変更はありません。実設定・認証・既存Memory・共有記録を保護し、保存済みの背景登録指示やSettingsを書き換えません。

## 確認

- 3者のCharacter適用範囲の節が一致し、5機能の用途と境界が同じであることを確認しました。
- 自然文全体への適用と、事実・識別子・数値・引用・権限・登録契機の維持を照合しました。
- 入口・README・Session Graph Skillの既存方針との整合、変更差分、差分check、固定commitの参照先を確認しました。

## 確認限界

新規host Sessionでの指示読込・行動、実Memory/Affectの操作、背景処理の実行時挙動と口調の安定性は未検証です。文書の整合確認を外部runtimeの動作保証とは扱いません。
