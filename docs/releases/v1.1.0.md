# natumekazuki/.codex v1.1.0

Codex向け設定・指示・Skillのリリースです。GPT-6の3モデル構成への刷新と共通規約の整理、test差分抽出の修正を含みます。

## 変更

- 親・サブエージェントの設定をGPT-6 Astra／Sol／Lunaに統一しました。Astraを親、Lunaを範囲が明確な一般作業、Solを複雑な実装・判断へ割り当て、hookで対象外モデルとAstra親からAstra子への起動を拒否します。[設定と担当範囲](https://github.com/natumekazuki/.codex/blob/af82341e212b5a740df3f38d220dc42fab2c7ff1/README.md#modelとrole)
- AGENTSを共通原則と条件付き参照へ整理し、開発・設計判断・test・UI・WithMateの詳細を分離しました。共通文書の参照先はユーザーhome直下の`.codex/`です。[共通指示](https://github.com/natumekazuki/.codex/blob/af82341e212b5a740df3f38d220dc42fab2c7ff1/AGENTS.md)
- 設計判断の調査・草案作成・採否確認、現行情報と履歴保存の境界を明文化しました。履歴はADRとリリースノートへ限定し、詳細リンクはリリース内容に対応するcommitへ固定します。配布資産の案内と共通ルールの置き場も分離しました。[設計判断・文書化](https://github.com/natumekazuki/.codex/blob/af82341e212b5a740df3f38d220dc42fab2c7ff1/docs/guides/design-decisions.md)
- WithMate機能の利用契機と、操作権限の正本への参照を整理しました。[WithMate利用方針](https://github.com/natumekazuki/.codex/blob/af82341e212b5a740df3f38d220dc42fab2c7ff1/docs/guides/withmate.md)
- test差分抽出で、挿入hunkの宣言位置投影と、宣言置換時の保持本文による対応付けを修正しました。曖昧な対応は停止し、成功時は旧本文と現行本文を保持します。[Git差分選択の契約](https://github.com/natumekazuki/.codex/blob/af82341e212b5a740df3f38d220dc42fab2c7ff1/skills/review-test-value/references/git-selection-v1.md)

## 互換性

- `v1.0.0`から維持対象としている`review-test-value`のCLI、構造化result、metadata v2、対応adapter、Git差分選択の契約を維持します。
- 配布設定はGPT-6構成へ更新しています。旧モデルの運用定義と`gpt56` profileを除去し、切替先を`sol` profileに変更しました。利用環境で3モデルの提供状態を確認する必要があります。
- 配布元の更新は、端末の実config・共通文書の配置や既存Sessionへの反映を自動では行いません。
