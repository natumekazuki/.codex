# v7.0.1

WithMate Session間の返信と送信後の重複報告省略を区別する、互換性のある説明修正です。

## 変更内容

[協同guide](https://github.com/natumekazuki/.codex/blob/bf51019d316761241f524329357c9b36c4e2553d/docs/guides/withmate-collaboration.md)の明示報告の段落を、「依頼元への返信は、指定の送信操作で届ける。送信後は同じ内容の最終報告を自分のSessionに重ねない。」へ整理しました。送信操作を先に行い、省くのは送信後の同内容の最終報告であることを明確にします。

## 互換性・更新時の注意

既存のsession.enqueue指定、保存後配送、失敗・結果不明時の扱いと製品の上位応答契約は変更しません。Skill・設定・配送機構の追加はありません。既存homeへは対象guideの差分だけを反映し、個人設定・認証・履歴等を保護してください。

## 確認範囲

3製品の局所差分、採用文案と周辺契約の整合、独立review、既存参照を確認しています。返信未実施の原因が旧文言であることを実証した修正ではなく、モデル行動や再発防止の完全性を保証しません。
