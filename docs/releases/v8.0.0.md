# v8.0.0

[共通コメント規約](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/docs/guides/code-comments.md)を導入します。宣言には役割と契約を、本文には分岐・反復・例外処理や長い処理の流れを記します。公開APIに限らず、非公開の主要処理と呼び出し形式を含むテストも対象です。

## 変更内容

- 新規・変更するテストでは、条件、期待する観測、検出したい故障と必要な根拠を、言語に合うドキュメントコメントに記します。[通常のレビュー](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/docs/guides/test-changes.md#通常のreviewで確認する)で、テストが守る契約と検出力、削除・移設後に残る保証を実装と合わせて確認します。必要なテスト実行と、別途必要な独立確認は引き続き行います。
- [UIガイド](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/docs/guides/ui.md)と[設計Skill](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/skills/design-ui-information/SKILL.md)では、利用者が終えたい作業から設計を始め、説明を足す前に原因となる操作や制約を外せるか考えます。比較や編集では広がった幅・高さを主作業に使い、結果の文言で既存の操作対象を不意に動かしません。短いフォームや本文の読みやすさ、意図した再配置、必要なエラー・回復情報は保ちます。実画面では代表的な条件で元の作業を最後まで行えるか確認します。
- WithMateの[通常子から直接親への報告](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/docs/guides/withmate-collaboration.md#明示報告turn終了親の受入)では、自力で進められる途中経過だけを配送せず、依頼単位で最終報告を1回届けます。判断が要る相談、重大障害の連絡、親の照会への回答は維持します。
- このリポジトリの開発用に [Git pre-commit](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/README.md#このrepositoryのgit-pre-commit) を追加します。ステージ済みの差分の空白・衝突マーカー、対象Pythonの構文と追加・変更した宣言のdocstring、変更に関係するテストを確認します。

## 利用時の注意

Git pre-commitはCodexの実行時hookとは別で、チェックアウトしただけでは有効になりません。利用先リポジトリでコメントの存在・配置・形式を強制する場合は、[導入手順](https://github.com/natumekazuki/.codex/blob/02e0c2b761d7d2dffcee74c5137081076eae2c55/docs/guides/code-comments.md#利用先での機械検査の導入)に沿って対象・上限・除外を決め、通常の検証コマンドへ接続してください。
