# v7.0.0

WithMate v7.0.0-preview.8の契約に合わせ、廃止されたMemory／Affectの運用指示を撤去し、統括・委譲・共有guideの判断と参照を整理したリリースです。

## 変更内容

- [WithMate利用guide](https://github.com/natumekazuki/.codex/blob/128b214e1c8784a609368373c2fbb4b9bb9cf891/docs/guides/withmate.md)から専用Memoryの検索・保存、Affect投影、背景三用途の指示を削除しました。Character定義に基づく会話表現、非公開記録と提出用成果物の境界、通常Session履歴、Graph・Glossaryは維持します。
- [Session Graph Skill](https://github.com/natumekazuki/.codex/blob/128b214e1c8784a609368373c2fbb4b9bb9cf891/skills/session-graph/SKILL.md)から廃止された背景用途を除きました。通常作業の文脈復元、要求・制約・判断の先行記録、Crew境界、競合・結果不明時の確認は維持します。
- [協同guide](https://github.com/natumekazuki/.codex/blob/128b214e1c8784a609368373c2fbb4b9bb9cf891/docs/guides/withmate-collaboration.md)と[委譲guide](https://github.com/natumekazuki/.codex/blob/128b214e1c8784a609368373c2fbb4b9bb9cf891/docs/architecture/subagent-workspace.md)で、全体統括・個別統括・Workerの担当、同じ成果の再開、継続中の指示、必要な根拠を渡す委譲を整理しました。Model／Depthは作業の不確実性と完了条件から選び、操作schemaは現在のruntimeを参照します。
- 共通guide・READMEの重複説明や契約の転記を減らし、入口から現行の正本へ辿れる構成にしました。
- 旧Memory／Character接続runbookを削除し、[Glossary接続案内](https://github.com/natumekazuki/.codex/blob/128b214e1c8784a609368373c2fbb4b9bb9cf891/docs/runbooks/withmate-repository-glossary.md)を独立させました。残存runtimeの診断で使う所有者環境変数を`WITHMATE_AGENT_RUNTIME_*`へ更新しました。

## 互換性・更新時の注意

Memory／Affect専用の利用手順とSession Graphの背景参照用途を廃止し、旧WithMate前提との共存を維持しないためmajor versionを更新します。この版のWithMate連携はv7.0.0-preview.8を基準とします。廃止機能の互換stubや代替storeは追加しません。

Skill名・配置入口、review-test-valueのCLI／result／metadata／adapter／Git差分選択、通常Session履歴read、Graph・Glossaryの残存契約と操作承認・データ保護は維持します。ルール配布物の更新はWithMate本体の更新・データ移行ではなく、実設定・認証・履歴・既存利用者データを削除しません。

既存homeへは差分を確認して必要な配布ファイルだけ反映してください。実configを設定例全体で置換しないでください。廃止した手動Memory MCP登録・専用permissionを整理する場合も、その対象を確認して回復可能に扱い、他の設定を保護します。継続中processが旧設定を保持する場合は新しいprovider Sessionで確認してください。

## 確認範囲

3製品の静的な契約整合と独立review、設定例の構文、Session Graph Skill validator、現行リンク・廃止指示の残存、Git差分を確認しました。Windowsの対象環境では3製品homeへの差分配置とsource一致、個人設定の限定整理、preview.8の現MCP契約を確認しています。

配置済みファイルと後続Codex Turnでの指示読取を、新しいprovider processでのconfig再読込、OpenCode／Claudeの新Session起動、モデル行動の改善と区別します。後者の包括的な実行検証は行っていません。WithMate本体のmigration成功や全Providerの実利用受入を保証するリリースではありません。
