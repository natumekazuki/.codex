# natumekazuki/.codex v4.3.2

`review-test-value`で、削除したTypeScript testの閉じ行だけが別の存続test内へ投影されるGit差分の抽出停止を修正しました。

## 変更

- [Git差分の対応付け処理](https://github.com/natumekazuki/.codex/blob/12ffd0654f73921de859a6b2cf2c9ce92c5cc77c/skills/review-test-value/scripts/git_diff_selection.py)で、宣言開始行が変更され、未変更行が空白・閉じ区切りだけの旧recordに対応候補が残らない場合は、`DELETED.before`へ削除前の本文とmetadataを保持します。別の旧recordが既に対応付けた存続testの`SURVIVED`を維持します。
- 内容一致候補がなく、置換hunkに未対応の現行宣言候補が複数ある場合は、閉じ行だけで一つへ絞りません。閉じ行間への本文・宣言の挿入も同じ判定で扱います。
- [Git選択契約](https://github.com/natumekazuki/.codex/blob/12ffd0654f73921de859a6b2cf2c9ce92c5cc77c/skills/review-test-value/references/git-selection-v1.md)と[回帰test](https://github.com/natumekazuki/.codex/blob/12ffd0654f73921de859a6b2cf2c9ce92c5cc77c/skills/review-test-value/scripts/test_extract_test_values_multilang.py)に、既対応候補への投影、複数新宣言を含む置換、不正な削除元metadataの拒否を反映しました。対象は[Issue #107](https://github.com/natumekazuki/.codex/issues/107)です。

## 互換性と更新

- 既存のGit差分選択契約を満たすためのpatch releaseです。CLI、構造化result、metadata v2、対応adapterの形式を変更しません。新しい依存・設定・データ移行はありません。
- 内容一致や単一の置換hunk候補による一意な対応を維持します。metadata追加とasync化の`SURVIVED`、意味を持つ未変更本文の曖昧な対応・内容と位置の競合に対する`RECORD_TRANSITION_UNRESOLVED`、不正metadataの診断を引き続き維持します。
- 既存の配置方法で`skills/review-test-value/`全体を更新してください。配布元の公開と端末runtimeへの配置は別です。本不具合の回避として、対象製品のtest配置・改行の変更、手動mapping、部分出力による審査は不要です。
