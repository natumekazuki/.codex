# v6.0.8

WithMate v6.5.0-preview.1に合わせ、Character表現の適用境界とMemory登録・添付の利用規則を更新しました。

## 変更内容

- [WithMate利用guide](https://github.com/natumekazuki/.codex/blob/70c95e86a15c0c64cef1197293ab20b7785c0462/docs/guides/withmate.md)で、Character表現を応答と非公開のSession Graph・手元記録の自然文へ適用し、repository内・外部向け成果物との境界を明確にしました。主体、事実・条件・状態、識別子、引用、検証結果の扱いは変えません。
- Memoryの単件・一括登録を区別し、項目ごとの保存済み・失敗・結果不明・未実行を確認する規則を追加しました。途中失敗を全件未保存と扱う無条件の再送を避け、本文・添付・quota等の制限はruntime契約に従います。
- 背景の対象Memoryへの添付と、背景各用途からの既存添付の復元について、呼出しごとの許可範囲とローカルwriteの境界を明記しました。read-only・対応Providerのplan、復元先、既存ファイルの保護を維持します。
- 背景threadの継続時も現在の指示・権限・操作結果を優先し、Character Memoryの標準指示では本人の語りと観察事実・解釈を区別することを明記しました。[Session Graph Skill](https://github.com/natumekazuki/.codex/blob/70c95e86a15c0c64cef1197293ab20b7785c0462/skills/session-graph/SKILL.md)にも非公開記録の表現と状態保持の境界を補足しました。
- [README](https://github.com/natumekazuki/.codex/blob/70c95e86a15c0c64cef1197293ab20b7785c0462/README.md)に、保存済み背景登録指示を新しい標準指示へ切り替える場合の`Use Preset`と確認観点を追加し、既存の接続・診断説明を更新しました。

## 互換性

指示文書とSkill本文の互換修正です。Skill名・配置入口、review-test-valueのCLI・構造化result・metadata・adapter・Git差分選択、およびSession GraphのMCP呼出契約は変更しません。通常会話の能動的なMemory読取と、Memory・Affectの自動登録を背景実行へ委ねる方針は維持します。実設定・認証・既存Memory/Affect・共有記録を変更せず、既存記録の一括変換や独自store・同期機構は追加しません。

WithMateに保存済みの背景登録指示は、この配布物の更新だけでは変わりません。[WithMate v6.5.0-preview.1の標準指示](https://github.com/natumekazuki/WithMate/blob/70024a5bb33d6ec050700ab6b4ad24f76dd930f2/docs/releases/v6.5.0-preview.1.md)を使う場合はSettingsで該当用途の`Use Preset`を選択してください。既存のカスタム指示を自動で置き換えません。

## 確認

- 変更差分の静的review、3者の共通guide・Skill・README検証節の一致、相対リンクと参照先、差分checkを確認しました。
- 3者のSession Graph SkillをSkill Creatorの`quick_validate.py`で検証しました。
- 応答・非公開記録と外部向け成果物、項目別の保存結果、添付のread/write権限、標準指示とカスタム指示の境界を照合しました。
- code、test、hook、model・権限・MCPの実設定に変更はありません。

## 確認限界

新規Codex・Claude・OpenCode Sessionでの指示読込と行動、背景生成、実Memory/Affectの登録、添付取込・復元の実行時挙動は未検証です。静的な文言整合やSkill構文の成功を、外部runtimeの動作保証とは扱いません。
