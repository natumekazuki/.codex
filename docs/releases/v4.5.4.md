# natumekazuki/.codex v4.5.4

WithMate 6.3.29の利用環境に合わせてMemoryの記録・参照方針と接続案内を整理し、規約の不要な再読と毎promptの再通知を減らしました。

## 変更

- [WithMate利用方針](https://github.com/natumekazuki/.codex/blob/4b0dd70da179c17fd03f59c20a98fdc11f321ba9/docs/guides/withmate.md)で、日常の小さな事実・好み・共有episodeも記録対象とし、話題の開始・切替・再開時に関連Memoryを能動的に参照する方針を明確にしました。想起と新規保存を分け、毎turnの件数ノルマは設けません。
- [接続案内](https://github.com/natumekazuki/.codex/blob/4b0dd70da179c17fd03f59c20a98fdc11f321ba9/docs/runbooks/withmate-character-context.md)をSessionへ自動供給されるmanaged HTTP接続に揃えました。設定例の手動登録を除き、STDIOは開発・診断用途に分離しました。
- [共通ルール](https://github.com/natumekazuki/.codex/blob/4b0dd70da179c17fd03f59c20a98fdc11f321ba9/AGENTS.md)は同じ作業で把握できる既読規約を再利用し、新規適用・更新の兆候・文脈欠落時に必要な対象だけを読み直します。
- [Session Graph](https://github.com/natumekazuki/.codex/blob/4b0dd70da179c17fd03f59c20a98fdc11f321ba9/skills/session-graph/SKILL.md)の起動条件を作業開始・中断からの再開・Compact復元と要求・制約・承認・判断・状態の変化へ整理しました。既存内容だけの説明・確認・言い換えは除外し、短い承認や訂正の記録は維持します。
- [hook設定](https://github.com/natumekazuki/.codex/blob/4b0dd70da179c17fd03f59c20a98fdc11f321ba9/hooks.json)からUserPromptSubmitの共通ルール再通知を削除しました。SessionStart・SubagentStartとPreToolUseの委譲制御は維持します。

## 互換性と適用

利用指示と接続説明を改善するpatch releaseです。Skill名・導入入口、review-test-valueのCLI・result・metadata・adapter・Git差分選択、Session Graphの保存・競合・cleanup契約は変更しません。Memoryの保存scope・重複確認・機密保護・操作権限を維持し、自動想起機構や新たな保存基盤は追加しません。

配布物の取得だけで端末localの設定は更新されません。既存の実設定・認証・Memory・共有記録を保持し、必要な差分だけを配置してください。接続URLと短命tokenは永続設定へ保存しません。
