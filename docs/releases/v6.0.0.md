# v6.0.0

Session Graphの共有記録をWithMateが提供するSession-bound MCPへ一本化しました。Skillは記録・復元の判断を担い、保存・共有・表示はWithMateが担います。

## 変更内容

- [Session Graph Skill](https://github.com/natumekazuki/.codex/blob/1a2a3bc0267e64a7b2196ac3f9afd689e81b9711/skills/session-graph/SKILL.md)は、話題・直近の変化・現行条件をMCPから取得し、要求・制約・承認を依存作業の前に記録します。判断・活動・観測・未解決の状態、内容上の主体と記録者、参照先の責務を区別します。
- [共通の入口](https://github.com/natumekazuki/.codex/blob/1a2a3bc0267e64a7b2196ac3f9afd689e81b9711/AGENTS.md)とhook・guideをMCP前提へ揃えました。read-only作業でも現在のSessionへ提供されたGraphの記録は許容しますが、他の外部write・ソース変更・承認等へ権限を広げません。
- 更新は読み取ったrevisionを使う原子的batchとし、競合時は再取得、保存結果不明時は対象IDの照合を行います。review結果の詳細はSessionFolderの結果ファイルを正本とし、Graphには要約と参照を置きます。
- 保存helper、専用test、Mermaidの例、旧検証referenceとCIからの呼出しを削除しました。独自の保存・描画基盤やCLI fallbackは追加していません。

## 互換性と利用条件

公開済みのSession Graphのmmd保存先とhelperのsnapshot・save・cleanup呼出し契約を廃止する破壊的変更のため、major versionを更新します。既存mmdの自動取込み・移行・削除は行いません。

WithMateが現在のSessionへ提供するSession Graph MCPが必要です。接続URL・短命tokenを永続設定へ登録せず、実行時のMCP instructions・tool説明・schemaに従います。MCPが利用できない場合を空のGraphや保存成功として扱いません。

review-test-valueのCLI・result・metadata・adapter・Git差分選択、認証・操作権限、既存利用者データの保護は維持します。ClaudeとOpenCodeにも同趣旨の定義を独立して反映しています。

## 適用範囲と確認限界

本版は配布資産の公開です。新規SessionでのSkill発見・依存宣言の挙動、Claude/OpenCode各providerでの実MCP接続、resume/Compact、競合・通信失敗の実試験、Graphの画面表示は、上記の静的確認・通常系保存とは分けて扱います。端末への配置と接続確認は別の実施結果を確認してください。
