# natumekazuki/.codex v2.1.0

指示の作成・見直しに、受け手の判断に必要な情報と提供条件を基準にする共通原則を追加しました。

## 変更

- 指示の追加・維持は、受け手が既に利用できる情報の不足と、改善する判断に基づいて評価します。文章量だけでなく、持ち込む前提、調査・確認・承認待ちの負担も扱います。
- 不足への対応は、元の指示の明確化と参照条件・提供先の調整を優先します。個別の禁止・例外・再通知は、それらでは解消できない具体的な不足を補う場合に用います。
- [共通AGENTS.mdの原則](https://github.com/natumekazuki/.codex/blob/932c1687ae466276773f4de2713c29b01770b779/AGENTS.md)として定義し、並列運用専用の手順や通常作業への審査工程は追加していません。

## 互換性

- `v2.0.0`の操作権限・承認条件、既存変更の保護、必須確認、互換性境界と残件の判断を維持する追加としてminor versionを上げました。
- `review-test-value`のCLI・構造化result・metadata v2・対応adapter・Git差分選択の契約、および既存hookの通知内容・条件は変更していません。

## 検証

- 不要な対象情報の追加、肯定形でも不要な調査を増やす指示、同じ作業場所にある既存変更の保護、履歴を持たない受け手への情報提供について、文書上の判断と既存規約との整合を確認しました。
- 対象差分の`git diff --check`、リリース一覧の参照先、詳細リンクの完全commit hashと固定先の内容を確認しました。
- モデルの行動を比較する実験、実環境への配置、新規Sessionでの読込・行動確認は未実施です。
