# v6.0.7

Memory・Affectの自動登録を背景実行へ分離し、通常会話での能動的なMemory読取と共有情報の利用規則を整理しました。

## 変更内容

- [Memory・Affect・共有情報の利用](https://github.com/natumekazuki/.codex/blob/357ce3e4476b06c68cca6eeb319c0c86bcf5a3ea/docs/guides/withmate.md)で、自動生成・登録は背景実行へ委ね、通常会話の自発保存・appraisal・終了前の保存漏れ確認を削除しました。明示的な保存依頼と、許可された訂正・forget・moveは維持します。
- [共通指示の入口](https://github.com/natumekazuki/.codex/blob/357ce3e4476b06c68cca6eeb319c0c86bcf5a3ea/AGENTS.md)で、関連する過去の好み・判断・共有経験が関係する場合は、判断・回答前に検索して本文まで読むことを明確にしました。話題や条件の変化を含め、作業途中にも適用します。既読本文の再利用と、検索0件・未取得・取得失敗の区別は維持します。
- 機能の提供を判定する分岐や利用環境の宣言を置かず、各機能をいつ使うかを直接記述しました。作業ファイル・review結果・草案・画像の保存先を現在のSessionFolderへ揃え、明示保存先と保存・共有できない場合の境界を維持しました。
- [委譲](https://github.com/natumekazuki/.codex/blob/357ce3e4476b06c68cca6eeb319c0c86bcf5a3ea/docs/architecture/subagent-workspace.md)では、子がMemory・Session Graph・Glossaryを直接利用できない場合の親による取得・記録と結果共有を明記しました。子のtool権限とSession bindingの制約は維持します。

## 互換性

指示文書の互換修正です。Skill名・配置入口、review-test-valueのCLI・構造化result・metadata・adapter・Git差分選択、およびSession GraphのMCP呼出契約は変更しません。Memoryの自動注入を行わず、Memory・Affectの自動登録を背景実行が担うruntimeを対象とします。背景用途が未設定・失敗した場合も、通常会話で代行しません。既存データ、認証・認可、機密保護、操作承認を維持し、独自の記憶storeや管理基盤は追加しません。

## 確認

- 通常会話と背景実行、MemoryとAffect、共有記録とrepositoryの正本、保存と操作権限の境界を照合しました。
- コード、test、Skill、hook、実設定、認証情報、Memory・Affect・共有記録への変更はありません。

## 確認限界

指示文書の配布更新です。新規Main／Auxiliaryでの読込・能動的読取・保存抑止・明示保存・Affect反映、背景生成、子のtool制限時の共有、画像の保存・提示の実行時挙動は未検証です。静的な文言整合を行動改善や外部runtimeの動作保証とは扱いません。
