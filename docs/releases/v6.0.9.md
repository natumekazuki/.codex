# v6.0.9

WithMate v6.5.0-preview.2に合わせ、背景処理の終了状態と入力エラーの診断説明を更新しました。

## 変更内容

- [診断の説明](https://github.com/natumekazuki/.codex/blob/fb39eab38f3d2a8bbcde0c1d29638a0d75d6de50/docs/runbooks/withmate-character-context.md)で、Agentの終了状態と各tool操作の成否・保存効果を分けて確認することを明記しました。`completed`を全件保存成功と扱わず、操作拒否だけで実行全体を`failed`へ読み替えたり、正常な登録不要と判断したりしません。
- `WITHMATE_MEMORY_INVALID_INPUT`のtool・field位置・制約・unionの代替条件から入力を修正する手順を追加しました。公開schema拒否の`effect: none`は当該呼出しについての結果であり、他の保存済み操作まで未実施とは扱いません。
- 変更なしの要求の繰返しや、入力拒否を権限拡大・CLI fallbackの許可へ読み替えることを避け、入力値・secretを追加dumpしない境界を明記しました。
- [READMEの現行仕様参照と確認観点](https://github.com/natumekazuki/.codex/blob/fb39eab38f3d2a8bbcde0c1d29638a0d75d6de50/README.md)を、[WithMate v6.5.0-preview.2](https://github.com/natumekazuki/WithMate/blob/edce188fd7f8e7cf6399821b40df9771d54eb63d/docs/releases/v6.5.0-preview.2.md)へ更新しました。

## 互換性

既存文書の互換修正です。AGENTS／CLAUDEの入口、共通guide、Skill、委譲、model・権限・MCP設定、hook、review-test-valueのCLI・result・metadata・adapter・Git差分選択、Session GraphのMCP呼出契約は変更しません。通常会話と背景実行の役割分担、Character表現の境界、既存データ・認証・操作承認を維持します。

WithMate側のProject解決・Auxiliary参照の修正や、背景Affectのinspect・根拠指定へ独自の回避策・権限拡大を追加しません。保存済みの背景登録指示とSettingsは、この配布物の更新では書き換えません。

## 確認

- 3者の診断説明とREADME検証節が、host固有の参照pathを除いて一致することを確認しました。
- 変更差分の静的review、差分check、固定commitの参照先を確認しました。
- Agent終了状態、操作診断、入力修正と同一要求の再送、当該呼出しの保存効果と他の保存済み操作の境界を照合しました。code・test・Skill・実設定の変更はありません。

新規host Sessionでの指示読込・行動、実Memory/Affectの操作、背景実行と入力拒否の実行時挙動は未検証です。文書の整合確認を外部runtimeの動作保証とは扱いません。
