# v5.1.0

GPT-6.1 Terraを追加し、Sol・Luna・Terra・Astraの4 modelから作業の要求に応じて選ぶ構成へ更新しました。

## 変更内容

- [modelとrole](https://github.com/natumekazuki/.codex/blob/3effd46b28e17d55f731f4fdfe18118b8052a7d5/README.md#modelとrole)は、通常の親・一般childに6.1 Sol medium、手順・期待結果が明確な作業に6 Luna high、視覚・文章・検証方法が明確な局所修正に6.1 Terra medium、高度な判断に6 Astra mediumを使います。手動Astra親profileのlowとStandard速度は維持します。
- [general_terra](https://github.com/natumekazuki/.codex/blob/3effd46b28e17d55f731f4fdfe18118b8052a7d5/agents/general_terra.toml)とregistry登録、SubagentStartの再通知対象を追加しました。汎用roleの権限・協働・結果返却の契約は共通です。
- [委譲基準](https://github.com/natumekazuki/.codex/blob/3effd46b28e17d55f731f4fdfe18118b8052a7d5/docs/architecture/subagent-workspace.md)は既存3 modelを含めて整理しました。taskの短さやtoken単価だけで決めず、下位modelの試行やTerraでの事前診断を必須工程にしません。
- [起動hook](https://github.com/natumekazuki/.codex/blob/3effd46b28e17d55f731f4fdfe18118b8052a7d5/hooks/subagent-fork-default.ps1)は4 modelの明示指定を許可し、それ以外のmodelとAstra→Astraを拒否します。`fork_turns = none`と他の起動引数の保持は維持します。

## 互換性

既存role名、親・一般childの既定、review-test-valueのCLI・構造化result・metadata・adapter・Git差分選択契約を維持する追加です。旧modelの復帰、依存追加、データ移行、操作権限や必須審査の緩和はありません。

今回はCodex固有のmodel・role・hook対象の更新です。ClaudeとOpenCodeはそれぞれの製品に適した独立構成を維持し、変更していません。

## 検証

- Windows hookの起動・標準入力契約はcmd／pwshを含む50 checksが成功しました。Terraの許可、旧model・未知modelとAstra→Astraの拒否、履歴継承の無効化、他引数の保持を確認しています。
- 8 TOMLの解析、4 roleのregistry参照・model・effort・共通契約、親と一般childの既定、再通知matcherの整合を確認しました。
- 変更したPowerShell 3 scriptの構文検査と差分checkが成功しました。

## 適用範囲と確認限界

配布資産の公開と端末への適用・hook承認は別の操作です。端末では既存`config.toml`の必要sectionだけを反映し、認証・MCP・無関係な設定やfileを保持してください。TerraにはCodex CLI 0.159.0以降が必要です。

検証は配布設定とhookのoffline確認です。Terraの実起動、新規sessionでの権限・hook承認、代表taskでの品質・所要時間・使用量の改善は実証していません。確認方法は[比較runbook](https://github.com/natumekazuki/.codex/blob/3effd46b28e17d55f731f4fdfe18118b8052a7d5/docs/runbooks/compare-subagent-roles.md)を参照してください。
