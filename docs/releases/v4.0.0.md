# natumekazuki/.codex v4.0.0

SessionFolderの共有記録を「入口と話題別のMermaid」へ変更し、現在地の見つけやすさと判断経緯の保持を両立しました。ブラウザーによる描画確認は原則非表示で行います。

## 変更

- [session-graph Skill](https://github.com/natumekazuki/.codex/blob/9d58d0c95bac41ad2e6beaecdff3b6b344fd3778/skills/session-graph/SKILL.md)は、`SessionFolder/session-graph/index.mmd`を入口にし、独立した追跡が必要な話題を別のmmdへ分けます。現在の状態と当時の判断を区別し、変更理由、未確認事項、ADR・Issue・実装・検証根拠との関係を図に残します。
- [保存helper](https://github.com/natumekazuki/.codex/blob/9d58d0c95bac41ad2e6beaecdff3b6b344fd3778/skills/session-graph/scripts/session_graph.py)は`--graph`で固定フォルダー直下の対象mmdを指定します。対象path・リンク・snapshotの対象一致を確認し、原文比較、短時間ロック、ファイル単位の原子的置換を維持します。複数ファイルの一括成功は保証せず、詳細図を先に保存してから入口を同期します。
- [共通AGENTS.md](https://github.com/natumekazuki/.codex/blob/9d58d0c95bac41ad2e6beaecdff3b6b344fd3778/AGENTS.md)と[再通知hook](https://github.com/natumekazuki/.codex/blob/9d58d0c95bac41ad2e6beaecdff3b6b344fd3778/hooks/implementation-restraint.ps1)は必須利用の契機・事前記録・権限境界を維持し、読む対象と保存・復元の詳細をSkillへ集約します。README、配布構成の案内、metadata、表現例、検証手順も揃えました。
- ブラウザーによる描画確認を原則headless／非表示とし、可視表示はユーザーの明示依頼または事前了承がある場合に限ります。[UI確認Skill](https://github.com/natumekazuki/.codex/blob/9d58d0c95bac41ad2e6beaecdff3b6b344fd3778/skills/design-ui-information/SKILL.md)とsession-graphの両方で、非表示でも実描画・必要な操作・取得画像を確認します。

## 互換性と更新

- `v3.0.0`の単一図の保存先とhelperの呼出し契約を変更するため、major versionを上げました。保存先は`SessionFolder/session-graph.mmd`から`SessionFolder/session-graph/`配下へ変わり、`snapshot`と`save`の両方で`--graph <ファイル名.mmd>`が必須になりました。旧snapshotは新しい保存先に再利用できません。
- 旧図の自動移行・削除は行いません。[移行・配置の確認手順](https://github.com/natumekazuki/.codex/blob/9d58d0c95bac41ad2e6beaecdff3b6b344fd3778/skills/session-graph/references/validation.md)に従い、対象と権限、更新停止の調整、要求・経緯・未確認・参照の保持を確認してから切り替えます。配布元の更新と実行環境への配置、既存記録の移行は別の操作です。
- 導入時は`skills/session-graph/`全体、共通AGENTS.md、hook、描画確認を更新した`design-ui-information`を整合した版へ揃えて配置します。利用先に独自の呼出し指示があれば確認し、他repository・他セッションを一律に変更しません。
- 記録の必須利用と指示の先行保存、read-only時の記録限定の書込み範囲を維持します。ソース変更、外部write、破壊的操作、Computer Useの権限は拡張しません。製品の正本をグラフへ移管せず、別台帳・専用viewer・自動監査も追加しません。
- `review-test-value`のCLI・構造化result・metadata v2・対応adapter・Git差分選択の契約は変更していません。
