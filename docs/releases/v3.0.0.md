# natumekazuki/.codex v3.0.0

SessionFolderを共有する作業セッションで、受けた指示と作業状態を単一のMermaidグラフへ先行記録する仕組みを追加しました。

## 変更

- [session-graph Skill](https://github.com/natumekazuki/.codex/blob/4065d6c4a32e520d40cad7fc508dbcb6ddac4d18/skills/session-graph/SKILL.md)で、指示・訂正の記録、状態更新、再開、共有編集、図としての確認方法を定義しました。保存helperは同じSessionFolderの競合更新を検出し、失敗時に既存の記録を保持します。
- [共通AGENTS.md](https://github.com/natumekazuki/.codex/blob/4065d6c4a32e520d40cad7fc508dbcb6ddac4d18/AGENTS.md)に対象作業での必須使用を定め、UserPromptSubmitとSessionStartのstartup・resume・compactで既存hookが入口を再通知します。
- `v2.1.0`タグ後の変更として、指示設計の共通原則を[AIエージェント向け規約・タスク指示](https://github.com/natumekazuki/.codex/blob/b236917934253a7edd9d27db1ac82eeeb35ca1a0/AGENTS.md)へ限定しました。

## 互換性

- `v2.1.0`までのread-onlyの調査・計画等に対し、指定SessionFolderの共有記録と更新用一時ファイルに限って書込みを許容します。先行記録を必須にする作業契約の変更を含むため、major versionを上げました。ソース変更、外部write、明示的な変更禁止に関する権限は拡張しません。
- `review-test-value`のCLI・構造化result・metadata v2・対応adapter・Git差分選択の契約は変更していません。

- [mainへの統合後CI](https://github.com/natumekazuki/.codex/actions/runs/36574271415)は、Windows／LinuxのPythonテストと多言語adapterテスト、Windowsのhookテストの全jobが成功しました。
- Windowsで保存helperの6テスト、`py_compile`、hookの直接実行、`git diff --check`が成功しました。変更テスト6件の専門レビューでは統合ブロッカーは見つかりませんでした。
- 独立したCodexセッションが同じSessionFolderの最新グラフを読み、既存内容を保持して更新できました。
- 同じSessionFolderでのWithMate Auxiliaryからの共有更新、手動Compact後の再読、hookの有効状態、Mermaidプレビューの可読性はユーザーが確認しました。
- 会話要約後にSkillと最新グラフを読み直せることを確認しました。ターン途中の自動Compactに伴うhookの実発火は個別に観測していません。
