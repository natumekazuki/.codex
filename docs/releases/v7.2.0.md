# v7.2.0

アプリ開発に適用する実装規約の基本セットを追加し、v7.1.0以降に既定branchへ反映済みのGPT-6.2対応も収録します。

## 変更内容

- 実装規約: [AGENTS.md](https://github.com/natumekazuki/.codex/blob/e703b71cfd9e44ec4292e8ac6015c869eb7789da/AGENTS.md)から[開発ガイドの基本セット](https://github.com/natumekazuki/.codex/blob/e703b71cfd9e44ec4292e8ac6015c869eb7789da/docs/guides/development.md#実装規約の基本セット)を参照します。初回は全体、通常の変更では関連範囲に適用し、既存の規約・検査を優先します。書式・命名・lint・型、配置・依存方向、公開契約のコメント、正常・失敗時の動作テストを扱います。commit前はstaged内容、push前はpush対象commit、merge前は実際の統合経路の統合候補を検査します。Git hookを使う場合は有効化方法を示して検査本体を共用し、CIの要否は統合経路で必要な保証から決めます。
- GPT-6.2対応（[#159](https://github.com/natumekazuki/.codex/pull/159)で反映済み）: [配布用設定例](https://github.com/natumekazuki/.codex/blob/1cf083077e869fa46b472339afab5bff028bd727/config.example.toml)、profile、native roleのSol・Astraを、それぞれ`gpt-6.2-sol`・`gpt-6.2-astra`に更新し、[委譲hookの許可モデル](https://github.com/natumekazuki/.codex/blob/1cf083077e869fa46b472339afab5bff028bd727/hooks/subagent-fork-default.ps1)も合わせます。旧Astraで起動済みの親にもAstraへの委譲制限を維持します。Luna・Terraのモデル指定は変更しません。

## 互換性・更新時の注意

新しい必須の運用ルールを追加するためminor versionを更新します。Skillの入口・CLI・出力契約や配布先は変更しません。実装規約は既存コードの一括改修、アプリへのGit hook・CIの一律導入、実装着手を遮断する新しい仕組みを伴いません。GPT-6.2対応後の委譲hookは旧Sol・Astraの明示的なモデル指定を許可しません。配布用設定例の更新は、個人設定の自動変更を意味しません。

## 確認範囲

v7.1.0からの版間差分、実装規約の入口と適用範囲、配布用のモデル指定と委譲hookを照合し、Windowsのhook検査58件を確認しました。アプリへの規約の適用、更新後の新規Sessionでの指示の読込、GPT-6.2の実起動は確認対象に含めていません。
