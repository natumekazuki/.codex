# natumekazuki/.codex v4.2.0

SessionFolderのレビュー結果・対応状況の管理を共通ルールにしました。保存指定を含むテンプレートプロンプトに依存せず、レビュー結果の保存、対応時の再読、指摘別の判断・修正・確認・引継ぎを扱います。

## 変更

- [開発・review・統合guide](https://github.com/natumekazuki/.codex/blob/fb7efe77ddf1d602e5d9c9e5a81d08c7ac15f437/docs/guides/development.md#sessionfolderのreview記録と対応管理)に、`SessionFolder/review-results/*.md`への保存と対応状況の更新を定義しました。レビュー対象・担当・結論・未確認事項を記録し、各指摘の分類と対応状況を分けます。修正済み・未検証を確認済みと扱わず、後追いの未登録・権限待ちも明示します。
- [共通AGENTS.md](https://github.com/natumekazuki/.codex/blob/fb7efe77ddf1d602e5d9c9e5a81d08c7ac15f437/AGENTS.md)の読込契機に、レビュー結果の確認、対応開始・再開、完了判断を追加しました。read-only依頼でも、提供されたSessionFolder内のレビュー結果・対応状況の記録を作成・更新できます。記録を含む変更禁止とruntime権限を優先し、ソース変更・外部writeの許可には広げません。
- [Session Graph Skill](https://github.com/natumekazuki/.codex/blob/fb7efe77ddf1d602e5d9c9e5a81d08c7ac15f437/skills/session-graph/SKILL.md)は結論・未解決の要約と結果文書への参照を担い、レビュー詳細や指摘別状態を複製しません。後追い課題をrepository指定の管理先へ登録した後は、その管理先を進捗の正本にします。
- [review template](https://github.com/natumekazuki/.codex/blob/fb7efe77ddf1d602e5d9c9e5a81d08c7ac15f437/templates/review.md)に対象・担当、指摘ID、対応状況、修正・確認結果、引継ぎ先の記載例を追加しました。固定の章立てや全欄の記入は要求しません。

## 互換性と更新

- 既存の`review-test-value`のCLI、構造化result、metadata v2、対応adapter、Git差分選択と、Session Graphの保存先・保存helper呼出し契約を維持します。共通のレビュー記録・対応管理を追加するminor releaseです。新しい管理基盤や保存helperは追加していません。
- レビュー完了、全件修正、統合、公開を分ける方針を維持します。非ブロッカー全件修正を統合条件にせず、既存の必須確認・承認条件に従います。
- 既存の配置方法で共通AGENTS.md、開発guide、Session Graph Skillを整合した版へ揃えてください。テンプレートを利用する場合は併せて更新します。配布元の更新だけでは端末の実環境へ配置されません。
- ユーザー指定の保存先は優先します。SessionFolderも保存先指定もなければ通常の応答で結果を返し、保存先を推測・新設しません。既存セッションの結果文書を一括移行・削除する変更はありません。
