# v6.1.0

WithMate V7のSession間協同と端末保存方針に対応しました。

## 変更内容

- [協同ガイド](https://github.com/natumekazuki/.codex/blob/b3cb865cc172905b5ebf513882be7b910b85f812/docs/guides/withmate-collaboration.md)を追加し、Role・入力来歴、背景確認、非同期の依頼と明示報告、三階層の相談・回答・取り下げ、方向別の通常送信とSteerを整理しました。
- Model・Depth・承認・Sandbox・契約経路とWorktree配置はWithMateの保存方針・実カタログを参照します。端末固有の暫定設定ファイルを配布要件にせず、保存設定の変更は明示指示に限定します。
- [WithMate利用ガイド](https://github.com/natumekazuki/.codex/blob/b3cb865cc172905b5ebf513882be7b910b85f812/docs/guides/withmate.md)にSessionFolder/Crew Folderの使い分けと、Character同士の友人としての距離感を明記しました。敬語等の個性、操作権限と成果物の文体は維持します。
- Session Graphの共有・復元方針、入口と配置案内をV7へ揃えました。

## 互換性

既存のSkill名・導入入口、review-test-valueのCLI/result/metadata/adapter/Git差分選択とデータ保護・操作権限を維持する機能追加です。WithMateの操作schemaは実行時に提供される契約を優先します。実config・認証・Memory・共有記録を置換せず、端末保存方針は配布物とは別管理です。

## 確認と範囲

3製品の静的整合・差分検査、preview.4の公開契約と方向別送信・三階層相談のシナリオ照合を実施しました。Codexの通常Workerとは依頼・明示報告・同一Workerへの追加依頼の二往復を確認済みです。ユーザーの受入・リリース指示に基づく公開です。

上記を3製品全体の実配送、Coordination/Steerの実行試験、変更前後の生成応答比較の成功とは扱いません。これらは今回の実施確認範囲外です。
